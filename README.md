# Train-RBAC — Staff admin RBAC lab

## Objectif
Projet d’entraînement consacré à la gestion de rôles et permissions dans une interface staff admin.

## Stack
- Next.js
- Node.js / Express
- MongoDB / Mongoose
- Express Session + MongoStore
- Helmet
- Rate limiting



## Ce que le projet montre
- Auth session
- Middleware requireAuth
- Middleware permission
- Routes staff protégées
- UI admin avec création, édition, suppression
- Gestion d’erreurs côté front

## Limites connues
- RBAC volontairement simple
- Pas encore de tests automatisés
- Pas de permission system par ressource/action
